| 项 | 值 |
|---|---|
| 桩节 | `.AXJvbGt`  VA=0x58000  Raw=0x52E00  Size=0xA73D |

## 3. 结构速查

### AKPH（桩节 +0x00 起）

| 偏移 | 含义 |
|---|---|
| +0x00 | 版本（=1） |
| +0x10 | 魔数 `AKPH`（0x48504B41） |
| +0x14 | 版本（=1） |
| +0x18 | 桩节 VA |
| +0x1C | stage2 载荷 VA |
| +0x20 | 解密长度 |
| +0x24 | 载荷长度 |
| +0x28 | 标志（0x40000000） |
| +0x2C | 子版本（1） |
| +0x30 | **4 字节 key 值** |
| +0x38 | 表 T1（32 字节，参与密钥派生） |
| +0x58 | 表 T2（32 字节） |

### AKPC（stage2 解密后，base = stage2VA）

| 偏移 | 含义 |
|---|---|
| +0x00 | 魔数 `AKPC`（0x43504B41） |
| +0x04 | 版本 |
| +0x08 | 桩节 VA |
| +0x0C | **原始 OEP（RVA）** |
| +0x10 | 节标志 |
| +0x18 / +0x1C | 重定位表 VA / 大小 |
| +0x20 | 特性位图 |
| +0x24 | **页表条目数** |
| +0x2C | 加密算法编号 |
| +0x30 | 导入项数 |
| +0x34 | 导入相关字节数 |
| +0x38 | 状态表大小 |
| +0x3C | **页表偏移** |
| +0x40 ~ +0x4C | 完整性/扫描相关参数 |
| +0x50 | 原始镜像大小相关 |
| +0x54 / +0x58 / +0x5C | 毫秒参数（守护线程周期等） |
| +0x6C | 校验值 |

### 页表（AKPC + tableOff，每条 0x14）

| 字段 | 含义 |
|---|---|
| +0x00 u32 | 页 VA（同时是页解密 IV 的一部分） |
| +0x04 u16 | 保留 |
| +0x06 u16 | 有效长度（末页可能 < 0x1000） |
| +0x08 u32 | 保留 |
| +0x0C u32 | 密文页 CRC 字段 |
| +0x10 u32 | 明文页 CRC 字段 |

> 注意：这两个 CRC 字段与**标准反射 CRC32** 不符（我们两种状态下计算的 CRC 都与它不同），
> 说明用的是变体或覆盖范围不同。脱壳不依赖它；解密正确性由 `AKPC` 魔数 + 与壳运行时
> 已解密页逐字节比对来保证。

### 运行时 ctx（stage1 构造，stage2 使用）

| 偏移 | 含义 |
|---|---|
| +0x00 | 模块基址 |
| +0x08 / +0x10 | 页状态表指针 / 容量 |
| +0x20 | 桩入口 |
| +0x28 / +0x30 | AKPH / AKPC 指针 |
| +0x38 | 页表基址 |
| **+0x58** | AES-256 密钥（32 字节） |
| **+0x7C** | 特性位图（所有反调试/完整性开关） |
| +0xB0 ~ +0xF8 | 解析后的 API 函数指针表 |
| +0x24C | "已触发"标记 |
| +0x36C | 首个错误码记录 |

### 页状态（每页 1 字节）

| 值 | 含义 |
|---|---|
| 0 | 已解密，可执行 |
| 1 | 已上锁（NOACCESS） |
| 2 | 待重加密 / 待处理（守护线程扫描对象） |
